# Administrator guide

What your own administrator needs to be able to do without calling us.

## Adding a user

1. Open the admin console.
2. **Users** then **New user**.
3. Set their role, their company and the objects they may see.
4. Save. They receive an invitation email and set their own password.

## Removing a user

Deactivate rather than delete. A deleted user takes their audit history with them, and that
history is what answers "who changed this" six months later.
